Add a rationale/explanation system to the NMAT mock exam simulator. Create a new file `artifacts/nmat-exam/public/rationales.json` with the content `{}` (empty object). If the file is missing or fails to load, silently fall back to an empty object. The question ID is derived from the image filename — for example, `questions/p1_verbal/p1_verbal_001_q.png` corresponds to ID `p1_verbal_001` by stripping the folder prefix and `_q.png` suffix. On the exam results page, for every question shown during review, add a button labeled "💡 Rationalize this Item". In the BM item editor (the right-side panel where the question image and correct answer are shown), add the same "💡 Rationalize this Item" button below the Question Image section with identical toggle behavior. Additionally, in the left-side item list, add a small 💡 indicator icon next to items that already have a rationale in `RATIONALES`. Do not modify any exam-taking logic, timer, scoring, answer key loading, or question bank probe logic — this feature only reads from `RATIONALES` and never writes to it from the UI. After creating `rationales.json`, also copy it to `artifacts/nmat-exam/dist/public/rationales.json`, and add a note in `replit.md` that every time `rationales.json` is updated in `public/`, it must be copied to `dist/public/` using: `cp artifacts/nmat-exam/public/rationales.json artifacts/nmat-exam/dist/public/rationales.json`
